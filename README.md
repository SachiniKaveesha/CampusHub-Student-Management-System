# CampusHub – Student Event & Information Management System

CampusHub is a full-stack, database-driven web application designed to transition student services from manual spreadsheets into a centralized digital platform.

## 🚀 Key Features
- **Role-Based Authentication:** Distinct portals and dashboards for Students and Administrators.
- **Dynamic Event Management:** Event scheduling, location mapping, and status controls.
- **Event Registrations:** Many-to-Many entity management linking students to activities.
- **Automated XML Synchronization:** Real-time synchronization of notices to `announcements.xml` via PHP DOMDocument.
- **Multimedia & Gallery:** Event photo uploads with server-side validation, coupled with audio and video integration.
- **Security & Integrity:** SQL sanitization via real escape strings, password hashing, and timezone alignment.

## 🛠️ Tech Stack
- **Backend:** PHP 8.x
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Data Exchange:** XML (DOMDocument)
